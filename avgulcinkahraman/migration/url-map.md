# URL ve içerik göçü

| Eski URL | Yeni hedef | Karar |
|---|---|---|
| `/` | `/` | Yeni ana sayfa; eski Kubio demo blokları taşınmaz. |
| `/hizmetlerimiz/` | `/hizmetlerimiz/` | Hizmet merkezi olarak yeniden kurulur. |
| `/hakkimizda/` | `/hakkimizda/` | Kişi odaklı profil ve özgeçmiş sayfası. |
| `/iletisim/` | `/iletisim/` | Çalışan form ve doğrudan iletişim kanalları. |
| `/kanser-ilaci-davalari/` | aynı URL | İçerik korunup yeni hizmet şablonunda geliştirilir. |
| `/aile-hukuku/` | aynı URL | Birincil aile hukuku sayfası. |
| `/aile-hukuku-2/` | `/aile-hukuku/` | Kalıcı 301. |
| `/kira-tespit-ve-tahliye/` | aynı URL | İçerik korunup geliştirilir. |
| `/makaleler/` | aynı URL | Ana makale merkezi. |
| `/blog/` | `/makaleler/` | Kalıcı 301. |
| `/hello-world/` | — | Trafik ve bağlantı yoksa 410; aksi durumda uygun hedefe 301. |

## İçerik modeli

- Hizmet: özgün başlık, kimler için olduğu, süreç, belgeler, sık sorulan sorular, ilgili makaleler ve iletişim eylemi.
- Makale: WordPress yazısı, kategori, yazar, yayın/güncelleme tarihi, içindekiler ve ilgili hizmet bağlantısı.
- Ana sayfa: hizmet özeti, gerçek güven unsurları, seçilmiş makaleler ve iletişim; ayrıntılı metinler alt sayfalarda tutulur.
